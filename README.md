# Amazon Homepage Clone usimg HTML & CSS

A responsive **Amazon Homepage Clone** built using **HTML and CSS** as a frontend practice project.

This project recreates the basic layout and visual structure of the Amazon homepage, including the navigation bar, search section, hero banner, product/category cards, and footer.

## 📌 Project Overview

This project was created as part of my frontend development learning journey to practice building a real-world website layout using HTML and CSS.

The main focus was on understanding:

* HTML page structure
* CSS layouts and positioning
* Flexbox
* Navigation bars
* Search bar design
* Hero sections
* Product/category cards
* Footer layouts
* Hover effects
* Using images as backgrounds
* Font Awesome icons

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## ✨ Features

* Amazon-style navigation bar
* Location section
* Search bar with category selector
* Sign-in and account section
* Returns & Orders section
* Shopping cart section
* Navigation panel
* Hero banner
* Product/category cards
* Footer with multiple sections
* Hover effects on navigation elements
* Amazon-style color scheme and layout

## 🎯 Learning Outcome

Through this project, I practiced creating a complete webpage layout from scratch using HTML and CSS.
It helped me improve my understanding of:
* Page structure
* Flexbox
* CSS styling
* Responsive layout concepts
* Background images
* Navigation design
* Component-like sections
* Frontend UI development
